🚀 Sistema PDI

A plataforma definitiva para a gestão administrativa e financeira de projetos de pesquisa acadêmica, desenvolvimento e inovação.

📖 O que é o Sistema PDI?

Imagine um assistente financeiro e administrativo criado especialmente para professores, pesquisadores, universidades e fundações de apoio (como FCPC, FASTEF, etc.)[cite: 1].

O Sistema PDI acaba com a confusão das planilhas de Excel e a papelada física, centralizando todo o dinheiro de um projeto de pesquisa, o pagamento de bolsistas e as compras de equipamentos em um só lugar[cite: 1]. A ideia é simples: devolver o tempo do pesquisador para a ciência, tirando de suas costas a burocracia complexa da prestação de contas governamental para órgãos como o TCU e CGU[cite: 1].

✨ Funcionalidades e Características (MVP)

📄 Leitura Inteligente (XML)

Importação de despesas através do envio do XML da Nota Fiscal eletrônica com extração de dados (CNPJ, data, valor) para acelerar a prestação de contas[cite: 1].

💰 Controle Orçamentário

Gestão clara do dinheiro dividido em categorias (Custeio, Capital, Bolsas)[cite: 1]. O saldo se atualiza sozinho assim que uma despesa é inserida, alterada ou estornada[cite: 1].

👥 Gestão de Equipes

Cadastro e alocação de coordenadores e bolsistas nos projetos, controlando prazos de vigência, valores das bolsas e compatibilidade[cite: 1].

🛡️ Auditoria Implacável

A arquitetura usa "Shadow Tables" (Lixeira Histórica). Toda exclusão ou alteração de dados gera um registro imutável com autoria e data, garantindo compliance público[cite: 1].

💻 Arquitetura e Stack Tecnológico

O sistema foi construído com as melhores práticas de engenharia de software, utilizando o padrão MVC (Model-View-Controller) e garantindo portabilidade[cite: 1].

🚀 Passo a Passo de Instalação

Instruções para configurar e rodar o projeto em um ambiente local ou servidor (focado em Debian/Ubuntu Linux)[cite: 1].

1. Instalação de Pré-requisitos
sudo apt update
sudo apt install -y php php-cli php-mbstring php-intl php-sqlite3 php-curl php-zip php-xml unzip git composer
2. Clonando o Repositório
git clone https://github.com/vlademiro575/pdi.git sistema-pdi
cd sistema-pdi
3. Instalando as Dependências e Configurando o Ambiente
composer install
cp env .env

Edite o arquivo .env com as seguintes configurações:

CI_ENVIRONMENT = development

database.default.DBDriver = SQLite3
database.default.database = WRITEPATH . 'database/pdi.db'
database.default.DBPrefix = ""
4. Permissões do Banco de Dados e Execução
mkdir -p writable/database
chmod -R 775 writable
php spark serve --host 0.0.0.0 --port 8080

Pronto! Basta acessar http://localhost:8080 no seu navegador para começar a utilizar o Sistema PDI[cite: 1].
